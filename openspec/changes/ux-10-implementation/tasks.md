## Standing Conventions (apply to EVERY task below)

- **Package manager**: `pnpm` only (never npm/yarn). No new dependencies.
- **Code style**: double quotes ALWAYS (`.prettierrc` → `singleQuote: false`). Every unit ends with `pnpm exec prettier --write <touched files>` then `pnpm exec prettier --check <touched files>` — touched files MUST be prettier-clean before commit.
- **Branch**: `master` (NEVER `main`). Conventional commits, one commit per work unit, in order C1..C9.
- **i18n**: every new visible string exists in `messages/es.json` AND `messages/en.json`, neutral Spanish (no voseo). `pnpm parity` after every i18n-touching unit (Units 1, 2; and any unit that adds strings).
- **Frozen domain**: ZERO changes in `src/core/`, `src/infrastructure/`, Mongoose models. Per-unit gate: `git diff --stat` (staged scope) shows no entries under `src/core/` or `src/infrastructure/`.
- **Test timeouts**: filtered runs during apply (default runner timeout OK for targeted files). Full-suite runs REQUIRE explicit timeout ≥ 2_700_000 ms (regulatory §14) — never retry a timed-out run without recording the real error.
- **TDD**: config `strict_tdd: true` — where a unit adds a component (C7 Alert, C8 FormField) or restructures behavior (C2 nav), the RED test task precedes the implementation task.
- **Paths with parentheses** in test commands MUST be quoted: `"src/app/(main)/pos"`.
- **`/reports` prohibition**: no unit creates a `/reports` route or any reports view (DEC-IA-09).
